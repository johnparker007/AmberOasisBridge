# Upstream reference snapshots

This directory contains faithful reference snapshots of legacy fruit-machine hardware emulation projects imported into this repository.

| Platform | Directory | Provenance | Import date | Source revision/version |
| --- | --- | --- | --- | --- |
| Epoch | `Epoch/` | Legacy source present in this repository as `AmberEmulationCores/Epoch Core` | Unknown | Unknown |
| JPM System 6 | `JPMSystem6/` | Legacy source present in this repository as `AmberEmulationCores/JPMSystem6Core` | Unknown | Unknown |
| MPU5 | `MPU5/` | Legacy source present in this repository as `AmberEmulationCores/MPU5Core` | Unknown | Unknown |

Git history records previous imported snapshots. These imported contents are reference material and are not maintained directly in this repository. Changes selected for integration must be ported to maintained code outside `Upstream/`.
